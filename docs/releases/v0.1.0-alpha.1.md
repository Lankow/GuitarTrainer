# GuitarTrainer v0.1.0-alpha.1 — Android early alpha

Prepared: 2026-10-29. GitHub prerelease for early testing; not Google Play production.

## Included

Capacitor Android package sharing the browser app's tuning studio, note/scale practice, Spider Walk, metronome, settings and translations. Audio processing stays local with no recording uploads or accounts. Microphone permission declarations and background session cleanup are implemented. The repository reserves a future iOS project path; no iOS app is included.

## Install

Download guitartrainer-0.1.0-alpha.1-debug.apk from this release's assets, open it on Android and allow installation from that source when prompted. Launch GuitarTrainer, enter a nickname, start listening and allow microphone access. Verify stopping or leaving the app clears the microphone indicator. SHA256SUMS.txt accompanies the APK.

This APK is debuggable and signed with the development machine's Android debug certificate, for early testing. A future production-signed app or a build signed on a different machine may require uninstalling this alpha, removing its local data. Do not assume seamless updates to a Play release. Native JSON export/import still needs device validation.

Package: io.github.lankow.guitartrainer. Version name: 0.1.0-alpha.1; version code: 1. Minimum SDK 24; target SDK 36. SDK configuration does not establish tested device coverage.

## Known limitations

No physical Android or real-guitar validation has been completed. Microphone accuracy, fast-note detection, latency, interruptions, file import/export, system Back behavior and phone layouts need testing. Permission-denial guidance mentions browser settings. Branding uses Capacitor template resources. App code is bundled; Google Fonts requires a network connection with fallback fonts offline. App data is separate from Chrome website data. iOS, production signing and Google Play publication remain deferred.

Report issues with device model, Android/WebView versions, app version, date and reproduction steps.
