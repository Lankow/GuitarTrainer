# GuitarTrainer v0.1.0-alpha.1 — Android early alpha (build 2)

Updated: 2026-10-31. This refresh replaces the original 2026-10-29 APK with the current application. It remains an early-testing GitHub prerelease, not a Google Play production release.

## Included in this refresh

- Current tuning studio, note/scale practice, Spider Walk, metronome, settings and translations.
- Experimental Chord Practice with Timed/Free modes, selectable chord sets and local microphone recognition. Real-guitar accuracy is unverified.
- Appearance brightness control and the transparent, theme-colored in-app guitar-pick logo.
- Matching Android adaptive, monochrome and legacy launcher icons; launcher colors follow native/system settings rather than in-app accent preferences.
- Shared browser/Android structure with a reserved future iOS project path. No iOS app is included.

Audio processing stays local with no recording uploads or accounts. Microphone permission declarations and background-session cleanup are implemented.

## Install or update

Download guitartrainer-0.1.0-alpha.1-debug.apk from this release's assets, open it on Android and allow installation from that source when prompted. Launch GuitarTrainer, enter a nickname if needed, start listening and allow microphone access. Verify stopping or leaving the app clears the microphone indicator. SHA256SUMS.txt verifies the APK download.

Package: io.github.lankow.guitartrainer. Version name: 0.1.0-alpha.1; version code: 2 (the original was 1). Minimum SDK 24; target SDK 36. SDK configuration does not establish tested device coverage. This refresh is signed using the same development debug certificate as build 1, so it is intended to install over it while retaining app data; the actual upgrade flow remains untested on a phone.

This APK is debuggable and intended for early testing. A future production-signed app or a build signed on a different machine may require uninstalling this alpha and removing its local data. Do not assume seamless updates to a future Play release. Native JSON export/import still needs device validation.

## Known limitations

No physical Android or real-guitar validation has been completed for this build. Pitch/chord accuracy, fast-note detection, latency, interruptions, file import/export, system Back behavior, phone layouts and launcher theming need testing. Chord recognition is experimental, especially during transitions, arpeggios, distortion or incomplete voicings. Permission-denial guidance mentions browser settings. Launcher icons are updated; splash resources remain provisional. App code is bundled; Google Fonts requires a network connection with fallback fonts offline. App data is separate from Chrome website data. iOS, production signing and Google Play publication remain deferred.

Report issues with device model, Android/WebView versions, app version/build number, date and reproduction steps.
